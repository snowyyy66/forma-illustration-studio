# Forma — конструктор иллюстраций

Веб-прототип для сборки композиций из исходных SVG-компонентов. Проект работает как статический сайт и готов к импорту в Vercel.

## Запуск локально

Требуется Node.js 18 или новее. Установка npm-пакетов не нужна.

```bash
node scripts/preview.mjs
```

Открой `http://127.0.0.1:4173`.

## Публикация на Vercel

Импортируй папку проекта в Vercel как **Other** / статический сайт. Build Command оставь пустым, Output Directory укажи `.`. `index.html`, `src/` и `assets/` обслуживаются как статические файлы; `vercel.json` включает чистые URL.

## Возможности прототипа

- Автоматически читает SVG-доски и группирует соседние контуры в кандидаты компонентов. У досок нет семантических имён, поэтому карточки нумеруются; двойной клик позволяет задать название и смысловые теги.
- Поиск по названию и по смысловым тегам, заданным в карточке компонента (без внешнего AI-запроса).
- Размеры компонентов L/S; роли «Главный» и «Фоновый»; три встроенные палитры и импорт JSON-палитры.
- Форматы 1200×630, 1080×1080, 800×1200 и 1600×900.
- Перемещение, поворот, пропорциональный масштаб, дублирование, удаление и порядок слоёв.
- Экспорт создаёт редактируемый SVG с путями и трансформациями, без растрирования.
- Состояние композиции сохраняется в браузере.

Палитру можно импортировать JSON-файлом такого вида:

```json
{
  "name": "Моя палитра",
  "background": "#D7CDF5",
  "backgroundObject": "#7864D7",
  "objectColors": ["#F9ECB0", "#F9A3AA", "#7864D7", "#181817"]
}
```

## Архитектура и ограничения

`assets/source/` хранит три уникальные исходные доски, переданные для задания. Оригиналы не меняются. Браузер разбирает SVG через DOM API, учитывает матрицы трансформации контуров, объединяет геометрически соседние пути и создаёт кандидаты компонентов. Метаданные и размещение живут в локальном состоянии браузера; серверной базы и аккаунтов нет. Экспорт сериализует только выбранные векторные пути с заполнениями, размерами и трансформациями.

В исходных досках почти нет имён слоёв и семантической разметки. Автоматическое выделение поэтому создаёт кандидаты, а человеку нужно проверить границы компонентов и при необходимости переименовать их. Рекомендации по метафорам в этой версии основаны на локальных тегах, не на вызове языковой модели.

В меню «Примеры» доступны три исходные сцены из экспортированной SVG-доски. Это редактируемые векторные кадры; для новых макетов добавляй отдельные фрагменты из библиотеки.

## AI-инструменты

- ChatGPT / Codex — помощь с анализом требований, проектированием и написанием кода.
- Внешние генераторы изображений и генеративные модели для создания/изменения иллюстраций не использовались. Все визуальные элементы взяты из предоставленных SVG.
