# Forma — редактор векторных иллюстраций

Forma — браузерный редактор для создания композиций из готовых SVG-компонентов. Выберите элементы из библиотеки или опишите идею словами, соберите сцену на холсте, настройте цвет и экспортируйте результат в SVG.

## Что можно сделать

- Найти компоненты по названию, тегам и ассоциациям.
- Подобрать элементы по текстовому описанию и собрать из них композицию.
- Размещать, перемещать, поворачивать, масштабировать и дублировать объекты; менять порядок слоёв.
- Выбрать размер библиотеки (L или S), формат холста и цветовую схему.
- Импортировать собственные SVG-компоненты и палитры в формате JSON.
- Сохранить готовую композицию в редактируемый SVG.

## Запуск локально

Понадобится Node.js 18 или новее. Установки зависимостей и сборки нет.

```bash
git clone https://github.com/snowyyy66/forma-illustration-studio.git
cd forma-illustration-studio
node scripts/preview.mjs
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173) в браузере.

## Как устроен проект

- `index.html` — разметка приложения.
- `src/app.js` и `src/workspace.js` — логика редактора и рабочей области.
- `src/styles.css` — стили интерфейса.
- `assets/source/` — исходные SVG-доски и примеры композиций.
- `scripts/preview.mjs` — локальный сервер для просмотра приложения.

При первом запуске приложение разбирает SVG-доски в браузере и строит из них каталог. Кэш каталога хранится в IndexedDB. Названия, теги, композиции и настройки сохраняются локально в браузере; они не синхронизируются с другими устройствами. Очистка данных сайта в браузере удалит локальные сохранения.

## Пользовательские палитры

Загрузите JSON-файл со следующими полями:

```json
{
  "name": "Моя палитра",
  "background": "#D7CDF5",
  "backgroundObject": "#7864D7",
  "objectColors": ["#F9ECB0", "#F9A3AA", "#7864D7", "#181817"]
}
```

`background` и элементы `objectColors` должны быть HEX-цветами вида `#RRGGBB`. `backgroundObject` задаёт цвет фоновых объектов и необязателен.

## Ограничения

Каталог строится из контуров исходных SVG-досок. В исходниках не все объекты подписаны, поэтому автоматическая группировка может потребовать проверки и ручной разметки. Подбор по описанию использует встроенные ассоциации и теги, без внешнего AI API. Forma собирает композиции из существующей геометрии и не генерирует новые иллюстрации.
