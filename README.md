# Forma — конструктор векторных иллюстраций

Веб-редактор для компоновки предоставленных SVG-объектов. Статическая версия запускается локально и размещается на Vercel без сборки и внешних npm-пакетов.

## Запуск локально

Требуется Node.js 18 или новее.

```bash
node scripts/preview.mjs
```

Открой `http://127.0.0.1:4173`.

## Что умеет редактор

- Фильтрует библиотеку по размеру исходников L/S и по роли объекта.
- Ищет по имени, тегам и словарю метафорических ассоциаций. Для точного подбора каталог нужно разметить: кнопка с карандашом на карточке задаёт название и теги.
- Собирает сцену из найденных объектов, включая фоновый объект по запросу; для портретного формата раскладывает объекты по вертикали.
- Добавляет векторные компоненты вручную; перемещает, поворачивает, дублирует, удаляет и меняет порядок слоёв.
- Фиксирует масштаб отдельных объектов. При смене формата вся композиция пропорционально адаптируется единым коэффициентом.
- Поддерживает три исходные цветовые схемы и импорт пользовательской JSON-палитры.
- Кэширует разобранный SVG-каталог в IndexedDB; проект и разметка хранятся в локальном браузере.
- Экспортирует композицию в редактируемый SVG: геометрия остаётся `<path>`, сохраняются атрибуты, трансформации и используемые определения SVG; растрирования нет.

### Пользовательская палитра

```json
{
  "name": "Моя палитра",
  "background": "#D7CDF5",
  "backgroundObject": "#7864D7",
  "objectColors": ["#F9ECB0", "#F9A3AA", "#7864D7", "#181817"]
}
```

## Архитектура

- `assets/source/` содержит исходные SVG-доски. Эти файлы служат неизменяемым источником геометрии.
- `src/app.js` загружает SVG браузерным DOM-парсером, получает координаты и трансформации путей порциями, группирует соседнюю геометрию в кандидаты и кэширует каталог в IndexedDB. Примеры сцен разбираются только при открытии.
- Компонент в редакторе — ссылка на векторный фрагмент и его метаданные. На холсте хранятся только ID компонента, роль, позиция, поворот, равномерный масштаб и видимость; полная геометрия не дублируется в `localStorage`.
- При экспорте исходные path-данные сериализуются в SVG с форматным `viewBox`, палитрой, порядком слоёв и трансформациями. ID клипов/градиентов переименовываются на слой, чтобы экземпляры не конфликтовали.
- Названия и теги библиотеки сохраняются в `localStorage`. Сервер, аккаунт и внешний AI API не требуются.
- Подбор метафоры работает локально по небольшому словарю ассоциаций и подтверждённым тегам. Сгенерированных изображений и новых объектов нет.

## Ограничение исходников

Экспорты досок содержат тысячи контуров, но почти не содержат групп, названий и семантики объектов. Поэтому извлечение по геометрической близости выдаёт **кандидатные фрагменты**, а не гарантированно проверенный каталог исходных объектов. Перед демонстрацией нужно визуально просмотреть карточки, при необходимости скорректировать границы/роли и задать имена и теги. Разметка пока хранится в браузере и не переносится в другой браузер автоматически. Это главный оставшийся риск соответствия исходному ограничению «объект должен просто копироваться целиком».

Сборка выполняется только из векторных путей пользовательских SVG. Если исходный SVG не размечен как целые объекты, редактор не может надёжно угадать границы без ручной проверки.

## Примеры и AI-инструменты

В меню «Примеры» доступны векторные сцены из `composition-examples.svg`; это исходные референсы, а не автоматически собранные из отдельных компонентов примеры.

- ChatGPT / Codex — анализ требований, проектирование, написание и ревью кода.
- Внешний AI API не используется в работающем сайте.
- Генерация и растрирование иллюстраций не использовались.

## Vercel

Импортируй репозиторий в Vercel как статический проект: Build Command пустой, Output Directory — `.`. Конфигурация находится в `vercel.json`.
